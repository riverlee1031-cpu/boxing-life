# Boxing Life V24 — 人生分流時間線版

主要更新：

- 左側時間線會永久顯示已走過的階段：
  - 2026 高一
  - 2027 高二
  - 2028 高三
  - 高中畢業後依選擇顯示大一～大四，或工作第一年～第四年
  - 之後再匯入職業新人、地區排名、世界挑戰者、生涯巔峰

- 高中畢業重大劇情：
  - 進大學邊讀邊練
  - 工作邊練

- 各階段事件會變化：
  - 高中：想家、段考、談戀愛、感情影響、分手
  - 大學：同學吵架、室友衝突、派對、實習、網紅偷拍、論文、大學畢業
  - 工作：加班、同事衝突、網紅偷拍、升職與拳擊衝突
  - 職業：經理、贊助、偷拍戀情、媒體與排名

- 每個階段仍約 5 回合後進重大劇情。
- 沒有勝場門檻。
- 能力點可以自由分配。
- 目前完全不放圖片。
