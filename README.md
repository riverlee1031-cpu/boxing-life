# Boxing Life V14 — No Win Gate

這版修正了「一直輸就永遠無法進下一階段」的問題。

## 核心改動
- **取消所有生涯階段的勝場門檻**
- 生涯改為隨著「時間 + 事件」自然推進
- 輸掉比賽仍然會進入下一章
- 勝敗只影響：排名、名氣、酬勞、健康、士氣、特殊比賽機會
- 職業執照事件不再要求業餘至少 6 勝
- 電視轉播特殊機會不再要求職業至少 2 勝，而是依生涯階段出現
- 保留所有事件圖片與橫版介面

## 舊存檔
V14 會嘗試讀取 V13 / V12 / V11 的舊存檔，並自動補上新的階段時間欄位。
