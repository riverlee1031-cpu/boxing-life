# Boxing Life V22 — Career Rhythm

這版把你上一個「好」視為三項都一起做：

1. **事件文案更像人生模擬器**
   - 不再只是「某件事發生了」。
   - 事件會有比較明確的人生情境、壓力與拳擊感。

2. **比賽節奏更清楚**
   - 第一年先生活與拳館適應。
   - 第一場業餘賽約在前兩個階段後出現。
   - 之後業餘賽按年份自然排入劇情。
   - 第三年之後自然出現轉職業選擇。
   - 職業階段約每兩個階段安排一次比賽。
   - 完全沒有勝場門檻。

3. **右側能力條更接近參考圖**
   - 每個能力獨立卡片
   - 顯示目前值 / 成長上限
   - 顯示成長區間與高能力成長遞減提示

4. **仍然完全無圖片**
   - 這版專心先把 UI 與玩法做順。
