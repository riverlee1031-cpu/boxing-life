# Boxing Life V18 — 台灣高中拳手海外篇

本版重新設計為偏 YaKyoLife 的深綠色文字生涯介面。

核心設定：
- 固定 18 歲開始
- 台灣高中畢業生
- 開局三選一：旅日 / 旅美 / 旅菲律賓
- 普通訓練、生活、校園與日常事件只顯示文字
- 重大事件、職業轉折、比賽、重大傷病、媒體風波等才顯示圖片
- 接下比賽後，普通事件暫停，直到比賽完成或取消
- 沒有勝場門檻，生涯會隨時間自然推進
- 單一 index.html，圖片已內嵌，不需要 assets 資料夾

GitHub Pages：
只要把 index.html 上傳到 repository 根目錄並覆蓋舊版即可。
