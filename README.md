# Boxing Life V19 — YaKyo-style Career UI

這版依照你提供的介面截圖重新整理：
- 左側：生涯時間線與選單
- 中央：人物資訊、年份、文字事件、生涯紀錄
- 右側：每期自主訓練骰與能力分配
- 固定 18 歲台灣高中畢業開局
- 開局三選一：旅日 / 旅美 / 旅菲
- 每期先擲 3 顆訓練骰，必須全部分配後才能進入本期事件
- 每一顆骰子都會產生訓練成果
- 能力越高，成長效率越慢
- 普通事件只顯示文字
- 重大事件、重大比賽、傷病、轉職業等才顯示圖片
- 接下比賽後，普通事件與自主訓練暫停
- 沒有勝場門檻，人生按時間自然推進
- 單一 index.html，圖片已內嵌，不需要 assets

GitHub Pages：直接覆蓋 repository 根目錄的 index.html 即可。
