# Boxing Life USA V3

- 男子 / 女子拳手都可建立
- 0-0 職業新人直接從美國開始
- 可選 Las Vegas、Los Angeles、New York、Miami、Houston、Philadelphia 為訓練基地
- 手機直式 UI
- 種子碼 RNG
- 每週事件卡
- 選項 + 1～6 骰子結果
- 訓練、媒體、贊助、傷病、減重、Promotion、短通知等事件
- 能力 XP 慢成長 + 隱藏天賦上限
- 美國各城市比賽邀約
- 賽前戰術選擇
- KO/TKO/UD/SD/Draw
- 排名、酬勞、人氣、健康、疲勞、備戰、減重風險
- 州級 → 美國區域 → 北美 → 國際 → 世界冠軍
- localStorage 存檔
