# Boxing Life V40 — 手機選單修正版

修正你截圖中手機版上方快速列的選單問題。

## 修正內容
- 手機 / 平板不再同時顯示「儲存」＋「☰ 選單」。
- 只保留一個「☰ 選單」。
- 生涯紀錄、儲存、重新開始全部收進下拉選單。
- 下拉選單改成從「☰ 選單」按鈕正下方展開。
- 不再使用 fixed top:48px，因此不會跳到頁面頂部。
- 快速列取消會裁切 dropdown 的 overflow-x:auto。
- 年份／階段文字過長時改成 ...，不會把選單擠出畫面。
- 320 / 375 / 390px 手機寬度另外縮小選單尺寸。

其餘 V39 功能全部保留。
