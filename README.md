# Boxing Life V23 — 高中留學快節奏＋能力點版

這版依照最新需求調整：

- **高一就開始留學**：16 歲從台灣前往日本 / 美國 / 菲律賓。
- **劇情推進更快**：每個階段約 5 回合。
- **第 5 回合後一定觸發年度劇情 / 大賽**。
- 完成年度劇情後，**不看勝負直接進下一階段**，不會卡關。
- **有能力點系統**：
  - 一般事件好結果可得到約 1～2 點。
  - 年度劇情 / 大賽通常給 2～6 點。
  - 玩家在右側自己分配到力量、速度、體能、防守、抗擊打、技術。
- 能力越高，加 1 點所需的能力點越多。
- **字體整體放大**。
- 桌機改成 **100vh 全視窗三欄**，左側時間線、中間劇情、右側能力點與選項。
- 目前依然 **完全不放圖片**。

GitHub Pages：只要覆蓋 repository 根目錄的 `index.html`。
