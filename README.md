# Boxing Life V11 — Horizontal Real Pixel Edition

這是重新整理的 V11：
- 桌機版改成橫向三區塊 UI（左側導覽 + 主劇情 + 能力/比賽側欄）
- 手機仍會自動切回直式版

- 美國、日本、菲律賓序章圖片各自獨立
- 事件圖片不再使用程式畫的簡陋 SVG
- 使用這次實際生成的 Q 版復古像素 PNG：訓練、比賽、醫療、網紅、夜生活、戀愛、冠軍、各國序章
