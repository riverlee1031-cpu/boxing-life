# Boxing Life V35 — 電腦 / 平板 / 手機響應式版

這版重做 Responsive UI，不是單純把桌機版縮小。

## 🖥 電腦版
- 1100px 以上維持管理遊戲三欄：
  - 左：人生階段 / 導航
  - 中：主要劇情
  - 右：能力、選擇、骰子、操作
- 左右欄使用 clamp() 自動調整，不會在 1366 / 1440 / 1920 螢幕比例差太多。
- 中間劇情欄永遠優先保留可閱讀寬度。

## 💻 平板 / 小筆電
- 861–1100px：改為兩欄。
- 左側大型人生導覽隱藏。
- 中間劇情 + 右側操作並排。
- 上方補一條小型快速列，可開生涯紀錄與儲存。

## 📱 手機版
- 860px 以下切成真正單欄。
- 順序變成：
  1. 人物資料
  2. 生涯圖示
  3. 當前劇情
  4. 能力 / 選擇 / 命運骰
  5. 最近紀錄
- 右側操作欄會自動搬到當前劇情下面，不需要先滑過所有紀錄才看到選項。
- 按鈕高度放大到適合手指點擊。
- 字體、卡片 padding、人物頭像、能力數值都會依手機縮放。
- 生涯路線圖改成橫向滑動，會自動對準目前階段。
- 手機生涯紀錄視窗改成底部彈出的全寬視窗。
- 390px / 375px / 320px 等窄螢幕都有額外縮放。
- 支援手機直式、橫式與 safe-area。

## 🎮 開局畫面
- 三國角色卡手機版改成橫式小卡，不會一張圖佔滿整個螢幕。
- 序章文字、輸入欄位、按鈕皆依螢幕尺寸調整。

V34 的旅日／旅美／旅菲文化事件全部保留。
