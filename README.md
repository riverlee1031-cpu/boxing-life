# Boxing Life V34 — 國家文化劇情版

## 核心更新
旅日、旅美、旅菲不再只是角色圖與國旗不同。
每條路線都有獨立的當地文化／生活／拳館事件池。

### 🇯🇵 旅日
包含：
- 拉麵吃壞肚子，必須決定休養還是硬去訓練
- 電車延誤與日本準時文化
- 高中文化祭拳擊攤位
- 拳館前後輩文化
- 溫泉恢復
- 工作聚餐與隔日訓練衝突
- 新年神社抽到大凶

### 🇺🇸 旅美
包含：
- Homecoming 與訓練衝突
- 路上遇到搶手機事件，制伏後可能影片爆紅，也可能受傷
- Open Sparring 影片在社群爆紅
- Thanksgiving 與控體重
- 美國醫療帳單壓力
- 開車去外地拳館 Road Trip 實戰
- 運動品牌商業拍攝

### 🇵🇭 旅菲
包含：
- Jeepney 塞車導致訓練遲到
- Brownout 停電，在高溫拳館繼續訓練
- Fiesta 與備戰飲食衝突
- 颱風導致拳館進水
- Barangay 拳擊活動
- 隊友家庭的星期日午餐
- Videoke 唱到半夜與隔天長跑
- 地方電視訪問與 Tagalog

## 事件觸發方式
- 每階段仍為約 4 回合。
- 第 2、4 回合仍會優先觸發特殊事件。
- 國家專屬特殊事件已加入特殊事件池。
- 其他普通回合約 55% 機率優先抽到該國的在地文化事件。
- 系統會避開最近出現過的事件，降低重複。

## 結果不是固定好事
同一個文化事件會依玩家選擇與命運骰出現不同結果。
可能增加能力、士氣、名氣與收入，也可能生病、受傷、花錢、掉狀態。
